# 地城迷蹤 · Roguelike 可遊玩測試版

回合制地城探索 roguelike。React + Vite。手機與桌面瀏覽器皆可遊玩。

## 開始遊玩

```bash
cd roguelike
npm install
npm run dev      # 開發伺服器
# 或
npm run build && npm run preview   # 正式建置預覽
```

## 操作

| 操作 | 鍵盤 | 畫面按鈕 |
| --- | --- | --- |
| 移動 / 攻擊 | 方向鍵 · WASD · HJKL | 十字方向鍵 |
| 待機一回合 | 空白 · `.` | 中央 ● |
| 喝治療藥水 | `Q` | 🧪 藥水 |
| 下樓（站在 `>` 上） | `>` · Enter | ⬇ 下樓 |

撞向敵人即可攻擊。踩到地上的道具會自動拾取。

## 目前已實作（測試版範圍）

- 隨機生成的房間 + 通道地城，逐層加深
- 視野 / 戰爭迷霧（看過的區域會以暗色記憶）
- 回合制移動與近戰戰鬥
- 敵人 AI：在視線內追擊玩家，否則隨機徘徊；共 7 種敵人，隨樓層變強
- 道具：治療藥水、金幣、武器（攻擊+）、護甲（防禦+）
- 經驗值與升級（提升上限體力 / 攻擊 / 防禦並回滿血）
- 階層推進，抵達第 8 層為測試版通關，可續玩無盡模式
- 死亡 / 通關畫面與重新開始
